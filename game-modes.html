Single Player

  1. Choose New Game to control all nine counselors as the story switches between them. Pick a full playthrough before choosing the cabin or Chapter 2 trail.
  2. For a guide with deliberate misses or timeouts, match its input settings. If you want Death Rewind, check when it unlocks and where it can send you back.
  3. Choose Continue to resume the save. Finish the story to unlock Chapter Select for that run.

Local · Two to eight players

Couch Co-op

Assign characters yourself

  1. Choose Couch Co-op from the main menu. Use Add Player until everyone has a slot. To rename a slot, highlight it, choose Edit Player, enter a name and choose Confirm.
  2. Highlight a player, move through the character carousel and choose Add Character for each counselor they will play. You can give one player multiple counselors. To move an assigned character, select the current player first and toggle the assignment off, then assign the character to the new player.
  3. Assign all eight characters in the carousel. Laura’s player also controls Max, who has no separate slot in this mode.
  4. Adding the final character opens the start confirmation. Choose Play. If a player has no character, a separate confirmation lists their name. Choose No to return and change the assignments, or Yes to continue with that player sitting out.

Randomize the assignments

  1. Add at least two players, then choose Quick Start. The game assigns all eight selectable characters and shows the lineup.
  2. Choose Shuffle to deal the characters again, Back to return to the player screen or Play to begin with the displayed lineup.

Hand over the controller

  1. At the handover, read the player’s name and pass them the controller. They confirm Ready? and make the choices and action inputs for that character.
  2. To resume, return to Couch Co-op and open the existing local save. After completing it, use Couch Co-op’s Chapter Select entry to replay with that save.

Online · One host and up to seven guests

Wolf Pack

Host or join a lobby

  1. Check that everyone has the same platform and game edition. A PS5 running the PS4 edition can join a PS4 session. An Xbox Series X|S running the Xbox One edition can join an Xbox One session. PlayStation requires PS Plus for online play. Xbox requires a Game Pass tier with console multiplayer.
  2. As host, choose Wolf Pack → Host game. Choose New game or select an existing Wolf Pack save.
  3. Choose Lone Wolf for host decisions or Pack Wolf for group voting. Invite up to seven guests from the online friends list.
  4. As a guest, accept the host’s invitation and wait in the lobby. If you’re using the free Prologue trial, install the edition that matches the host’s full game. The host chooses Start game after everyone joins.

On Steam, solo trial progress carries over when you buy the full game on the same account. 2K · matching game editions · 2K · trial invitations · Steam trial · PlayStation online play · Xbox online play

Decisions, action prompts and exploration

Lone Wolf
Guests vote on the choices they see. The host makes the final decision.
Pack Wolf
The majority vote decides. The host breaks ties, including opposite votes in a two-player session.
Action prompts
Guests can answer group quick-time prompts. In GamePro’s four-player PS5 test, two correct inputs passed a dodge. The host controls aiming and shooting.
Exploration and pickups
The host moves and interacts. Guests can place a marker with the cursor to point out an object or direction. The audited PC build uses a ten-second ping cooldown.
Pack Stats
When a chapter records tracked votes, the results screen shows how the group voted on them.

Rejoin or continue a save

  1. Have the host return to the menu when a guest needs to rejoin. The PC game rejects joins during an active session. If the host leaves, that session ends.
  2. The same host opens Wolf Pack → Host game and selects the existing save. Invite everyone from the lobby again and choose Start game to resume from the checkpoint.
  3. When the run is complete, the host can use Chapter Select from that Wolf Pack save. If a guest cannot connect, check the full installation, edition and game update on both systems.

Automatic story · Ending spoilers below

Movie Mode

  1. Open Movie Mode from the main menu. Choose a preset below, or choose Director’s Chair to set the counselors’ traits.
  2. Confirm Play. On the audited PC build, the confirmation records Creature Feature before the story begins.
  3. Watch the story advance through choices, exploration and action scenes automatically. For story and collectible awards, use an interactive walkthrough.

What the presets show

Everyone Lives
All nine counselors survive. In the recorded ending, Laura kills Silas and Caleb freezes after his curse lifts. Recorded credits and newspapers · Interactive Rough Night walkthrough
Everyone Dies
The preset targets the nine counselors. Travis, Bobby, Constance and Silas survive in the recorded credits. Recorded credits and newspapers · Interactive Massacre walkthrough
Gorefest
This preset requires the Deluxe Bonus Content Pack. It favors violent scenes and can leave counselors alive. In a recorded PS5 run, Abigail dies at the pool house and Jacob survives. The recording uses the separate Classic Horror filter. Recorded fate cards from 1:58:10

Set up Director’s Chair

  1. Choose Director’s Chair. Cycle through all nine counselors in the character carousel, including Max. Each counselor has their own four settings.
  2. Set the four traits using the labels below. Each row lists the favorable, random and unfavorable settings in that order. The scene determines what each setting does.
  3. When the traits are set, choose Start Game and confirm Play. The game applies the traits as scenes are reached. Use the preset menu for a movie with the designated counselor survival or death outcome.
Under pressure
Adept · Erratic · Clumsy. Used for quick-time actions and button mashes.
In conversation
Sympathetic · Inconsistent · Antagonistic. Used for dialogue and interrupts.
In fight or flight situations
Composed · Conflicted · Flustered. Used for combat and Don’t Breathe.
While looking around
Vigilant · Distracted · Oblivious. Used for exploration routes and decisions about where to go.

Choose traits for specific scenes

Before choosing Start Game, select the counselor and set the trait for the scene you want to see. The changes below take effect only if the story reaches that scene. Use the first or last setting to choose a specific branch. The middle setting lets each scene roll its own result.

Chapter 1 · Jacob and Emma’s bracelet

  1. Choose Jacob. Under While looking around, choose Vigilant to send him past the bracelet before he enters the lodge.
  2. Choose Oblivious to skip the bracelet. Both exploration branches still send Jacob into the lodge for the bags. The bracelet can protect Emma if she later encounters infected Jacob. Lasting consequences of the bracelet

Chapter 3 · Abi’s Trail Camera, call and kiss

  1. Choose Abigail. Set While looking around → Vigilant to have her inspect the Trail Camera before meeting Nick. Oblivious skips that stop.
  2. Set In conversation → Sympathetic to have Abi call back when Nick calls and take the kiss interrupt if it appears. Antagonistic passes up those interrupts. This is a separate setting from the camera stop. Interactive woods choices

Chapter 6 · Jacob’s Memory Card

  1. Choose Jacob and set While looking around → Vigilant. If he reaches the walkway alive, his movie route takes him to the camera for the Memory Card. With Oblivious, he leaves without inspecting it.
  2. Both movie branches skip the exploration prompt for Justice. Use the interactive walkthrough if you want to pick up the tarot card yourself.
Chapter 9 · Ryan’s bedroom and Kaylee’s Letter

Set Ryan to Vigilant under While looking around. He checks the jewelry box for Kaylee’s Letter and inspects the cabinet before trying the side door. With Oblivious, he goes straight to the door. Interactive bedroom choices

Chapter 9 · Who explores the scrapyard

  1. Set Dylan’s While looking around if he and Kaitlyn reach the yard together. Set Kaitlyn’s trait for the branch where she reaches it alone. To cover either branch, give both the same setting.
  2. Vigilant adds the stop at the Freakshow remains after the lake view. Oblivious skips it. Both branches continue toward the crane. Interactive crane outcomes

Chapter 10 · Kaitlyn’s Trail Cam Footage

  1. Choose Kaitlyn and set While looking around → Vigilant. If she reaches lodge exploration, her route checks the boxes for Trail Cam Footage before the attack.
  2. Oblivious skips the footage. Both branches still check Abi’s bag and the window, then continue to the attack. The movie routes skip the exploration prompt for The High Priestess.
