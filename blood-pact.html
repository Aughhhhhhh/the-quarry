Before you start

  • All three achievements. Replay Chapter 2 if your save already has the four prologue clues, the Hunting Notice and Camp Plaque, and the Chapter 1 cabin break-in. Check the game’s Clues menu and Paths → Down the Rabbit Hole. Dylan can recover the three other cabin clues in Chapter 5. Start in Chapter 1 if the cabin stayed locked or the lodge clues are missing. Start at the prologue if a clue from there is missing.
  • Blood Pact only. Replay Chapter 3 while the group is alive. If you left the cabin locked, use the two-bite crane route in Chapter 9. If you broke in, use the radio-hut bite. Either cabin choice works for the infection award.
  • Inputs. Set Aim Assist to Off. Keep directional prompts, mashes, interrupts and Don’t Breathe on manual settings. Pass each prompt unless a step says to miss or let it expire. Accessibility settings for planned failures
