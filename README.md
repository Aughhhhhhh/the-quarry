# The Quarry Field Guide

An unofficial guide to the 2022 game by Supermassive Games and 2K. The static site publishes from the root of `main` on [GitHub Pages](https://aughhhhhhh.github.io/the-quarry/).

Open the [guide home](https://aughhhhhhh.github.io/the-quarry/) to browse chapters, endings, collectibles, achievements, characters, and camp reference. To preview search, saved checklists, and old bookmark redirects locally, run `python -m http.server 8712` from the repository root and open [localhost](http://localhost:8712/).

The [epilogue catalog](https://aughhhhhhh.github.io/the-quarry/epilogue.html) covers character fate cards and newspaper variants, with filters for character and outcome. The [PC recap asset index](https://aughhhhhhh.github.io/the-quarry/epilogue.html#recap-index) links the game’s recap text to guide routes and identifies text skipped by the story.

Run `python tests/check_site.py` to verify the checklist, achievement, path, chapter and epilogue counts, internal links, and assets. The site’s [fact-check notes](https://aughhhhhhh.github.io/the-quarry/reference.html#sources) describe the sources and the limits of the ending audit.
