# The Quarry Field Guide

An unofficial guide to the 2022 game by Supermassive Games and 2K. The static site publishes from the root of `main` on [GitHub Pages](https://aughhhhhhh.github.io/the-quarry/).

Open `index.html` for the guide. To preview it over HTTP and test saved checklist progress, run `python -m http.server 8712` from the repository root and open [localhost](http://localhost:8712/).

The [epilogue catalog](https://aughhhhhhh.github.io/the-quarry/epilogue.html) covers character fate cards and newspaper variants, with filters for character and outcome.

Run `python tests/check_site.py` to verify the checklist, achievement, path, chapter and epilogue counts, internal links, and assets. The site’s [fact-check notes](https://aughhhhhhh.github.io/the-quarry/#sources) describe the sources and the limits of the ending audit.
